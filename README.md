# Dataset

The dataset used in this project is the **DataCo SMART Supply Chain Dataset**, obtained from Kaggle.

Due to the large file size, the original dataset is not included in this GitHub repository.

**Dataset:** DataCo SMART Supply Chain Dataset

**Source:** Kaggle

**Original dataset size:** 180,519 records and 53 columns.

The dataset was loaded and processed in Google Colab. The preprocessing included missing-value treatment, duplicate checking, date conversion and validation, outlier detection using the IQR method, and Min-Max normalization.

The final processed dataset contains **180,519 records and 51 columns**, with **0 missing values** and **0 duplicate records**.
